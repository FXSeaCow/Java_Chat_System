# Nhật ký sử dụng AI

Thư mục này ghi lại phần việc AI hỗ trợ trong từng task Jira (project **JC**).

## Quy ước

- Mỗi sprint trên Jira là một thư mục `sprint-<số>-<tên-không-dấu>/`.
- **Mỗi task cha là một file** `JC-<số>-<tên>.md`. Các subtask là các mục `##`
  bên trong file đó.
- Làm xong subtask nào thì thêm mục của subtask đó vào file và commit cùng code.
- Tên file và thư mục viết không dấu, không có khoảng trắng.

## Mẫu

```markdown
# JC-xx – Tên task

## JC-yy – Tên subtask

### Yêu cầu
### Kế hoạch của AI
### AI đã làm gì
```
